Delivery execution

What happens when the door does not open

Failed delivery attempts cascade. Each attempt costs money. Redelivery adds cost and extends time to customer. Multiple failures lead to return to warehouse.

Strategy

✓ Automated: Ring bell, wait, attempt safe place
✓ Redelivery: Initiate next-day attempt or return
✓ Route: Send to safe place, collect point, or return
✓ Return: Back to warehouse if all attempts exhausted

The van is already there

Once in the delivery vehicle, the package is committed. Every minute in the van costs money. The goal is to get the parcel into the customer's hands on the first attempt.
